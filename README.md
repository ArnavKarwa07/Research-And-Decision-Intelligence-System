## Core product thesis

The system is not a chatbot with multiple agents.

It is a decision-support system that uses a conversational interface to coordinate autonomous research, evidence validation, data analysis, adversarial review, and decision synthesis.
- `DATA_MODEL.md` - persistent entities and relationships
- `AGENT_CONTRACTS.md` - standardized input/output responsibilities for agents
- `TESTING.md` - unit, integration, adversarial, regression, and eval testing
- `DEPLOYMENT.md` - deployment, CI/CD, operations, monitoring, and recovery
